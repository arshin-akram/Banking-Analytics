# 🏦 Banking Analytics
## 📌 Overview

This project focuses on analyzing banking transaction data to uncover patterns in customer activity, debit and credit behavior, and overall financial performance. The objective is to support data-driven decision-making by transforming raw banking data into meaningful KPIs and interactive dashboards.

## 🛠 Tools & Technologies

Excel – Data exploration and dashboard creation

SQL(MySQL) – Data aggregation and KPI analysis

Power BI – Interactive visual analytics

Tableau – Dashboard visualizations

## 📂 Datasets

The analysis is based on two banking-related databases:

Banking Analytics Database

Credit & Debit Transactions Database

Each dataset contains structured transaction and customer-level banking information used to derive key financial metrics.

## 📈 Key Insights

Bank Analytics Dashboard:

1. Loan demand is concentrated within specific age groups and regions, indicating targeted customer segments.
2. Home Loans, Services, and Business loans show the highest demand across loan purposes.
3. A noticeable number of delinquent and default loans highlight potential credit risk areas.
4. Gaps in the loan verification process suggest opportunities to strengthen risk assessment and approval controls.

Credit & Debit Analytics Dashboard:

1. Credit transactions outweigh debit transactions in certain branches, indicating surplus cash flow.
2. Transaction patterns vary significantly across branches, reflecting operational and customer behavior differences.
3. Debit Card transactions show high frequency, highlighting strong customer reliance on digital payment methods.

## Overall Insights

1. Fraud Monitoring: High-value debit transactions (₹4,500 and above) can be treated as potential fraud indicators and flagged for closer monitoring.
2. Customer Segmentation: Working-age customers drive higher loan demand, while older customers tend to maintain stronger account balances.
3. Branch-Level Performance: Branches show varied financial behavior, with some generating stronger credit inflows and others experiencing higher debit activity.
4. Transaction Behavior: Debit cards dominate transaction frequency, reflecting a strong preference for digital payment methods.
